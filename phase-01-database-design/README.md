Phase 1 - Database Design

Objective

Design the database structure for an e-commerce system before creating the actual MySQL tables.

This phase focuses on:

* Understanding business requirements
* Identifying entities
* Identifying attributes
* Identifying relationships
* Understanding primary keys and foreign keys
* Designing the Entity Relationship Diagram (ERD)
* Applying basic normalization principles

Entities

The initial database will contain the following entities:

1. Customer
2. Address
3. Category
4. Product
5. Supplier
6. Product Supplier
7. Order
8. Order Item
9. Payment
10. Shipment
11. Review

Deliverables

* Business requirements
* Entity and attribute definitions
* Relationships between entities
* Entity Relationship Diagram

SQL Concepts Covered

This phase is focused on database design rather than SQL implementation.

Concepts introduced:

* Entities
* Attributes
* Relationships
* Primary keys
* Foreign keys
* One-to-many relationships
* Many-to-many relationships
* Normalization
